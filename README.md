# PDF 轉 DXF 工程圖轉換

在瀏覽器內把 PDF 工程圖或圖片轉成 DXF 的工具。檔案只在本機瀏覽器處理，不會上傳。

線上使用：<https://bowenlolz.github.io/pdf-dxf-converter/>

## 功能

- **向量 PDF**：線段、折線、矩形原樣轉出；圓與圓弧轉為真正的圓弧物件；文字轉為可編輯文字；保留 PDF 原圖層。
- **掃描圖與圖片**（JPG、PNG、BMP、WebP）：以線條中心描線；斜拍照片可用「四角拉正」校正。
- **比例與座標**：填圖面比例、用「量測與校正」以已知距離校正，或用「座標定位」指定兩點以上的實際座標（例如 TWD97）。
- **整理**：共線短線合併為虛線、相接線段接成聚合線、依 PDF 裁切範圍裁線、框選範圍只轉部分圖面。
- **輸出**：AutoCAD 2010 或 2000 格式；多頁可分開或合併；圖層可依原圖層、顏色、線寬分層，並可套用圖層對應表。

## 使用方式

1. 選擇 PDF 或圖片，勾選要轉的頁面。
2. 填圖面比例與 DXF 繪圖單位。
3. 按「疊合」核對轉換結果是否與原圖重合。
4. 按「轉換並下載」。

## 限制

- 掃描圖與圖片裡的文字、符號會變成短線段，不會還原成文字。
- 原圖把文字畫成線條時（SHX 字型常見），轉出後仍是線條。
- 沒有內嵌字型的中文 PDF，文字可能亂碼。
- 需要網路連線以載入 PDF 讀取元件（pdf.js，經由 cdnjs）。

## 檔案

整個工具是單一的 `index.html`，不需要建置或安裝。
